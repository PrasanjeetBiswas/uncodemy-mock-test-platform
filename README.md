# Uncodemy Mock Test Platform

A scalable, high-performance interactive Mock Test platform built for Uncodemy.

## Features
- **Comprehensive Test Series:** Domain-specific tests for Python, Data Analytics, Full Stack Development, and more.
- **Real-time Exam Environment:** Timed mock tests mimicking real-world exams.
- **Detailed Analytics:** Instant result analysis and performance review after every test.
- **Highly Optimized:** Achieves 95+ Lighthouse performance scores on mobile and desktop.
- **Accessible:** Built with WCAG accessibility standards in mind.

## Tech Stack
- **Frontend:** React, Vite
- **Styling:** CSS Modules, Lucide React (Icons)
- **Deployment & Tooling:** Node.js

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/PrasanjeetBiswas/uncodemy-mock-test-platform.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
